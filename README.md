# Evaluación Final del Modulo 2:

Creando una landing page completa y moderna

# Objetivo General

La misión era crear una "landing page" (página de aterrizaje) de una sola página, totalmente adaptable (responsive), utilizando el framework Bootstrap. Integrando HTML semántico para la estructura, Bootstrap para el diseño y los componentes, y JavaScript básico para la interactividad. Todo el proyecto debe estar bajo control de versiones con Git y alojado en éste repositorio público de GitHub.

# Elige Tu Proyecto!

Se escogio la alternativa A: _Landing Page para una Conferencia de Tecnología 💻_

#### Descripción:

Crea una landing page dinámica y atractiva para promocionar una próxima conferencia de tecnología. El objetivo es informar a los visitantes sobre el evento y animarlos a registrarse.

# ✨ Características principales:

- Navbar Sticky - Barra de navegación fija con enlaces a todas las secciones.
- Hero Section - Sección principal con gradiente, título y boton.
- Evento - Tarjetas con información clave.
- Oradores - Cards con fotos, nombres y biografías de speakers.
- Agenda - List group con el cronograma del evento, horarios destacados.
- Formulario de Registro - Campos para nombre, email y cargo con validación.
- Modal de Confirmación - Se muestra al completar el registro exitosamente.
- Footer - Con enlaces a redes sociales.

# 🎨 Diseño:

- Minimalista y profesional
- Completamente responsive
- Scroll suave entre secciones
- Colores modernos (púrpura y azul)
- Efectos hover en cards y botones

# Estructura semantica en HTML5:

1. <header> para el navbar
2. <nav> principal y redes sociales
3. <main> contenedor principal
4. <section> para cada sección
5. <article> para tarjetas de características y oradores
6. <footer> para pie de página

## Otros elementos semanticos

- Headings jerárquicos correctos (h1 → h2 → h3)
- <time datetime> para fechas y horarios
- Atributos name en inputs del formulario
